# Field

ورودی متن، عدد و انتخاب تاریخ با برچسب بالای آن و پیام خطا زیر آن.

**ساختار:** `<div class="f"><label class="f-label">…</label><input class="field">…<div class="err-msg">…</div></div>`. فیلد عددی (موبایل، کد ملی، کد) با کلاس `ltr` چپ‌چین است و اعداد فارسی نمایش می‌دهد؛ فیلد متنی `txt` راست‌چین. `field-btn` یک دکمه با ظاهر فیلد است که باتم‌شیت انتخاب (مثل DateWheel) را باز می‌کند. `otp` برای کد ۵ رقمی. خطا: کلاس `err` روی فیلد و `has-err` روی `.f`، و فیلد یک بار `shake` می‌خورد.

**حالت فعال:** خط ink و هاله‌ی `focus`. خط عادی `line` کنتراست کمی دارد (۱.۵:۱)؛ برچسب بالای فیلد آن را جبران می‌کند.

- باید: پیام خطا بگوید چه اشتباه است و چطور درستش کنند («شماره باید ۱۱ رقم باشه و با ۰۹ شروع بشه.»).
- باید: ورودی عدد، ارقام فارسی و عربی را هم بپذیرد.
- `hint` (خط‌چین `hint-line`) فقط برای اطلاعات «حالت تست».
