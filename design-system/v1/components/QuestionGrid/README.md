# QuestionGrid

شبکه‌ی شماره‌ی سؤال‌های دفترچه‌ی فعلی، داخل باتم‌شیت؛ هم وضعیت را نشان می‌دهد و هم برای پرش به سؤال است.

**ساختار:** `.grid` پنج‌ستونه از `.cell` دایره‌ای ۵۴px (خط ink، سایه‌ی سخت کوچک). جواب‌داده `ans` (پر `pri`، متن سفید)، سؤال فعلی `cur` (حلقه‌ی بیرونی `pri`)، علامت‌دار با نقطه‌ی `.f` روی `terra`. زیرش `.legend`.
