# LevelBreakdown

عملکرد به تفکیک سطح سؤال (ساده، متوسط، سخت) در یک کارت نمایشی، با رتبه‌ی فرضی کنار هر سطح.

**ساختار:** یک `card` با سه `.lv`؛ هر کدام عنوان، `x/y` با وزن ۹۰۰، `.bar` سبز و یک خط: «اگه N سؤالِ متوسط رو هم درست زده بودی: **رتبه‌ی ۷** · ۸۵٪». ته کارت یک `note` که می‌گوید رتبه‌ی فرضی در رتبه‌بندی ثبت نمی‌شود.
