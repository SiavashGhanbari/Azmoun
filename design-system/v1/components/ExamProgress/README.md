# ExamProgress

پراگرس‌بار آزمون: یک تکه برای هر دفترچه، یک دایره‌ی شمارنده که تعداد سؤال‌های ردشده را نشان می‌دهد، و یک دایره در انتها با تعداد کل سؤال‌ها.

**قاعده:** فقط وقتی جلو می‌رود که دانش‌آموز با دکمه («بعدی»، «قبلی»، شبکه‌ی سؤال‌ها، دفترچه‌ی بعدی) از سؤال رد شود؛ انتخاب گزینه آن را تکان نمی‌دهد. سؤال بی‌جواب هم حساب می‌شود. درست یا غلط بودن هیچ‌وقت نشان داده نمی‌شود.

**ساختار:** `.xtrack` شامل `.seg-b` به نسبت تعداد سؤال هر دفترچه (`flex: n`)، پر `green`، دفترچه‌ی تمام‌شده `done` (پر `green-muted`)؛ `.knob` ‏۳۸px روی `green-dk` با متغیر `--p` (درصد پر شدن دفترچه‌ی فعلی) و `.xend` روی `track`. بدون برچسب زیرش. با هر پیشروی، دایره یک bump فنری دارد.

در هدر آزمون همراه با دکمه‌ی بستن، عنوان دفترچه و تایمر (`timer`، در ۳ دقیقه‌ی آخر `low` قرمز با نبض) در یک هدر چسبان قرار می‌گیرد.
