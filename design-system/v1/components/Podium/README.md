# Podium

سکوی سه نفر اول رتبه‌بندی: اول وسط و بلندتر، دوم سمت چپ و کمی پایین‌تر، سوم سمت راست و از همه پایین‌تر.

**ساختار:** `.podium` با `direction: ltr` تا ترتیب دیداری ثابت بماند، سه `.pod` به ترتیب `p2`، `p1`، `p3`؛ هر کدام آواتار، نام کوچک با حرف اول فامیلی، نمره و `.blk` (اول `pri` با رقم سفید و تاج `mustard`، دوم `sage`، سوم `terra`). بلوک‌ها با رشد فنری از پایین بالا می‌آیند. اگر کاربر جزو سه نفر است، آواتارش حلقه‌ی `pri` می‌گیرد.
- باید: نام‌ها همیشه کوتاه‌شده (اسم + حرف اول فامیلی) برای حریم خصوصی بچه‌ها.
