# QuestionBlock

بالای هر سؤال: شماره‌ی سؤال در دفترچه و دکمه‌ی «علامت بزن»، بعد صورت سؤال و در صورت نیاز شکل.

**متن سؤال:** سبک `question`، راست‌چین، `text-wrap: pretty`. دو کلمه‌ی آخر (یا سه تکه، اگر آخرش علامتی مثل «؟» باشد) با فاصله‌ی نشکن به هم چسبانده می‌شوند تا یک کلمه یا علامت تنها در خط آخر نماند.

**شکل:** `q-img` یک دکمه‌ی سفید با خط و سایه‌ی سخت است و با زدنش نسخه‌ی بزرگ در باتم‌شیت باز می‌شود؛ برچسب «بزرگ‌نمایی» گوشه‌ی پایین‌چپ.

**علامت زدن:** `btn btn-ghost btn-xs`؛ روشن با `flag-on` (پر `terra-soft`، متن `terra-ink`، پرچم پر) و یک تکان کوچک پرچم.
