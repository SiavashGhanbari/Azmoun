# DateWheel

انتخابگر چرخشی سه‌ستونه برای تاریخ شمسی (روز، ماه، سال) داخل باتم‌شیت.

**ساختار:** `.wheel` با `.wheel-band` (نوار انتخاب `pri-soft`) و سه `.wheel-col` به ترتیب روز، ماه، سال (از راست). هر ستون یک scroll با `scroll-snap`، یک `.wsp` (۸۸px) بالا و پایین و آیتم‌های `.wi` ‏۴۴px. آیتم وسط `on` و بقیه با فاصله کم‌رنگ می‌شوند. تعداد روزها با ماه عوض می‌شود (۱–۶: ۳۱، ۷–۱۱: ۳۰، اسفند: ۲۹ یا ۳۰).

- باید: کلیک روی آیتم هم آن را به وسط بیاورد؛ با هر پله یک لرزش خیلی کوتاه.
