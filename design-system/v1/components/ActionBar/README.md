# ActionBar

نوار ثابت پایین صفحه برای اکشن‌های اصلی، تا دکمه‌ها همیشه زیر انگشت باشند.

**ساختار:** `.actions` (ستونی) یا `.exam-foot` (ردیفی) با زمینه‌ای که از `bg` به شفاف محو می‌شود؛ دکمه‌ی اصلی بالا، ثانویه‌ها زیرش؛ دو ثانویه‌ی کنار هم در `.row2`. صفحه‌ای که نوار اکشن دارد کلاس `has-act` می‌گیرد تا محتوا زیرش پنهان نشود.
