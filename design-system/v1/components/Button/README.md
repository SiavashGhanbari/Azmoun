# Button

دکمه‌ی کپسولی اپ در دو نوع اصلی (پر بنفش با خط و سایه‌ی سخت) و ثانویه (پر خاکستری شفاف، بدون خط و سایه).

**کی:** هر صفحه حداکثر یک دکمه‌ی `btn-primary` دارد؛ کار امن‌تر یا برگشتی همیشه `btn-ghost` است. دکمه‌ی بدون پس‌زمینه یا خط نداریم؛ حتی کم‌اهمیت‌ترین کار (مثل «حذف از سبد») یک ghost با `btn-danger` است.

**ساختار:** `<button class="btn btn-primary">` یا `btn btn-ghost`. اندازه‌ها: پیش‌فرض ۵۴px تمام‌عرض، `btn-sm` (۴۲px)، `btn-xs` (۳۴px، با آیکون ۱۶px)، `btn-sq` (مربع ۵۴px برای دکمه‌ی آیکونی در نوار آزمون). حالت‌ها: `disabled`، کلاس `loading` (برچسب شفاف + اسپینر)، `btn-danger` برای متن قرمز.

**رفتار:** دکمه‌ی اصلی هنگام فشردن ۳px پایین می‌رود و سایه‌اش صفر می‌شود؛ ghost ۳٪ کوچک و کمی تیره می‌شود. برچسب اصلی سفید (`on-fill`) و وزن ۸۰۰.

- باید: برچسب فعل باشد و دقیقاً بگوید چه می‌شود («شروع آزمون»، «ارسال کد تأیید»).
- باید: دکمه‌های کنار هم هم‌اندازه باشند (`row2` یا `flex:1`).
- نباید: دو دکمه‌ی اصلی در یک صفحه یا باتم‌شیت.
