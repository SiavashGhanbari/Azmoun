۲۱ آواتار سیاه‌وسفید با لهجه‌ی بنفش، ساخته‌شده با Humation Avatar Maker (humation.app/avatar). ۲۴۰×۲۴۰، همیشه داخل دایره با خط `ink` نمایش داده می‌شوند. دانش‌آموز یکی را در پروفایل انتخاب می‌کند؛ بقیه‌ی شرکت‌کننده‌ها هم از همین مجموعه آواتار می‌گیرند. قبل از استفاده در محصول نهایی، مجوز استفاده‌ی Humation بررسی شود.
