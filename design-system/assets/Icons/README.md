آیکون‌های خطی ۲۴×۲۴ اپ آزمون، خط ۱.۸px با گوشه و سر گرد، تک‌رنگ به رنگ `ink` (#1d1d1b). در کد به‌صورت SVG درون‌خطی با `currentColor` بیایند تا رنگ را از متن بگیرند. جهت‌ها راست‌به‌چپ‌اند: `icon-back` به راست، `icon-chev` و `icon-arrowL` به چپ. `icon-crown` تنها آیکون رنگی است (پر `mustard`) و فقط بالای سکوی اول می‌آید.
