تصویرسازی‌های خطی اپ (۱۶۰×۱۲۰): خط `ink` ‏۱.۸px، پرهای `illus-purple`، `sage`، `illus-terra` و `mustard`، سایه‌ی نقطه‌ای `terra`. کتاب: خانه و ورود؛ ساعت: انتظار نتیجه؛ سیبل: مأموریت‌ها؛ حباب: سبد سؤال؛ جام: رتبه‌بندی؛ برگه: کار تمام‌شده؛ گوشی: شماره‌ی ثبت‌نشده؛ کلید: کد دعوت. در اپ برق‌ها چشمک می‌زنند و کل تصویر آرام بالا و پایین می‌رود.
