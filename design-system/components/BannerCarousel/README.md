# BannerCarousel

بنر چرخان بالای خانه برای خبرها و پیشنهادهای اپ (آزمون بعدی، کلاس رفع اشکال، دعوت دوست).

**ساختار:** `.bn-wrap` ← `.bn` (اسکرول افقی با scroll-snap) ← `.bn-it` به‌صورت دکمه با تون `pri`، `sage` یا `terra`؛ تیتر، یک خط توضیح، `.bn-cta` و یک تصویرسازی در `.bn-art`. زیرش `.bn-dots`.

- باید: هر بنر یک پیام و یک کار؛ چون کلیک‌خور است خط `ink` و سایه‌ی `hard` دارد.
- باید: هر ۵ ثانیه خودکار جلو برود و با لمس کاربر چند ثانیه بایستد؛ با `prefers-reduced-motion` بدون انیمیشن جابه‌جا شود.
- نباید: بیشتر از ۴ بنر؛ قیمت و پیام خرید مستقیم برای بچه (آن‌ها جایشان بخش والدین است).
