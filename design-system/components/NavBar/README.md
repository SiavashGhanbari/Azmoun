# NavBar

نوار پایین شناور کپسولی با پنج تب: خانه، آزمون‌ها، مأموریت‌ها، رتبه‌بندی، پروفایل.

**ساختار:** `<nav class="nav">` با دکمه‌هایی شامل آیکون ۲۲px و برچسب `nav`. تب فعال `on`: کپسول `pri-soft` پشتش (`.pill` با پرش فنری) و برچسب پررنگ. شمارنده‌ی روی تب `.dot` روی `terra`. ۱۴px بالاتر از لبه‌ی پایین و ۱۶px از کناره‌ها.
- نباید: بیش از پنج تب. صفحه‌هایی که اکشن پایین دارند (آزمون، فرم‌ها، قوانین) نوار ندارند.
