# MissionPath

فهرست مأموریت‌ها به شکل یک مسیر عمودی؛ هر مأموریتی را می‌شود شروع کرد.

**ساختار:** `card tl` با یک ستون `green-soft` در راست و `.tl-step`ها. انجام‌شده `done` (آیکون ✓ روی `green-dk`، عنوان خط‌خورده، تکه‌ی ستون `green-step`، دکمه‌ی ghost «دوباره انجام بده»)؛ انجام‌نشده `cur` (آیکون پخش روی `pri`، دکمه‌ی اصلی کوچک «شروع مأموریت»). اولین انجام‌نشده بج `pri` «پیشنهاد» دارد. ترتیب: از ضعف سطح ساده به سخت.
- نکته: آیکون پخش به راست است (آیکون‌های رسانه در راست‌به‌چپ آینه نمی‌شوند).
