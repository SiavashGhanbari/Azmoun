# StatTile

کاشی عددی داشبورد خانه: رتبه، تراز، تمرین و سبد معلم.

**ساختار:** `.tile-grid` دوستونه از دکمه‌های `.tile`: عنوان `cap`، عدد بزرگ (۲۶px/۹۰۰، با `tabular-nums`) و یک خط کمکی. واحد یا «از N» داخل `<small>` کنار عدد می‌آید.

- باید: هر کاشی به صفحه‌ی همان عدد برود؛ قبل از اعلام نتیجه به‌جای عدد «—» و زیرش «بعد از نتیجه».
- نباید: بیشتر از ۴ کاشی؛ عدد بدون زمینه (همیشه یک خط کمکی دارد).
