# RankBadge

نمایش بزرگ رتبه در قصه‌ی نتیجه، با دو چیپ زیرش.

**ساختار:** `.taraz > b` روی `pri` با خط `ink`؛ عدد از تعداد کل شرکت‌کننده‌ها تا رتبه‌ی دانش‌آموز پایین می‌آید. زیرش `.wf-chips` با `.chip-up` (سبز، خبر خوب: «از N نفر جلوتری») و `.chip-up.plain` (خنثی: درصد کل).

- باید: در قصه‌ی نتیجه فقط رتبه بیاید؛ تراز جایش کارنامه، کاشی خانه و رتبه‌بندی است.
- نباید: استفاده برای عددی غیر از رتبه.
