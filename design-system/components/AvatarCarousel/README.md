# AvatarCarousel

انتخاب عکس پروفایل با ورق زدن؛ آواتاری که وسط می‌ایستد انتخاب‌شده است.

**ساختار:** `.avc-wrap` ← `.avc` (اسکرول افقی با scroll-snap، تمام‌عرض) ← `button.avc-it`. آواتار وسط `on` می‌گیرد: بزرگ‌تر، کاملاً پررنگ و با حلقه‌ی `pri`؛ بقیه کوچک‌تر و کم‌رنگ‌اند. زیرش `.avc-ctl` با دو `icon-btn` (قبلی و بعدی) و شمارنده‌ی «۵ از ۲۱».

**جای استفاده:** مرحله‌ی چهارم ثبت‌نام (انتخاب با ایستادن روی آواتار ثبت می‌شود) و باتم‌شیت «عکس پروفایلت رو انتخاب کن» در پروفایل (با دکمه‌ی «همین رو می‌خوام» تأیید می‌شود).

- باید: زدن روی هر آواتار آن را به وسط بیاورد؛ دکمه‌های قبلی و بعدی برای وقتی که کشیدن سخت است.
- نباید: شبکه‌ی چندردیفه‌ی آواتار؛ با ۲۱ عکس، ورق زدن خواناتر است.
