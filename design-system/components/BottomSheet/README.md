# BottomSheet

پنجره‌ی پایین‌صفحه برای تأیید، توضیح یا انتخاب، بدون ترک کردن صفحه.

**ساختار:** `.overlay` (پرده‌ی `scrim`) و داخلش `.sheet` (زمینه‌ی `surface`، گوشه‌های بالای `radius-sheet`) با `.handle-zone` (دستگیره)، تیتر `h2`، متن و `.acts` (ستون دکمه‌ها: یک اصلی، بقیه ghost).

**رفتار:** با حرکت فنری از پایین بالا می‌آید، با کشیدن دستگیره بیش از ۹۰px یا زدن روی پرده بسته می‌شود. وقتی شیت باز است، توست بالای صفحه نشان داده می‌شود.

**کی:** تأیید قدم‌های برگشت‌ناپذیر («بری دفترچه‌ی بعدی؟»)، تبریک و راه‌حل، مرور آموزش، شبکه‌ی سؤال‌ها، انتخاب تاریخ و آواتار.
- باید: کار امن («برگردم و جواب بدم») دکمه‌ی اصلی باشد وقتی کار دیگر برگشت‌ناپذیر است.
