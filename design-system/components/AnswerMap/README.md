# AnswerMap

نقشه‌ی جواب‌ها: هر سؤال یک خانه، به ترتیب خود آزمون و جدا برای هر دفترچه.

**ساختار:** `.tiles-wrap` ← برای هر دفترچه `.tiles-b` با عنوان `cap` و شبکه‌ی `.tiles`. خانه‌ها `ok` (سبز)، `bad` (قرمز) یا `none` (خاکستری).

**دو حالت:** در کارنامه خانه‌ها دکمه‌اند، شماره دارند (۱۰ ستون) و با زدنشان راه‌حل باز می‌شود. در قصه‌ی نتیجه فقط‌نمایشی‌اند (`<i>`، ۱۲ ستون، بدون شماره) و یکی‌یکی برمی‌گردند.

- باید: همیشه همراه راهنمای رنگ (`.legend`)؛ رنگ تنها حامل معنا نباشد.
