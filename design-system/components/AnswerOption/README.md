# AnswerOption

گزینه‌ی جواب کپسولی با شماره‌ی دایره‌ای در ابتدا؛ مهم‌ترین چیز کلیک‌خور اپ.

**حالت‌ها:** عادی (سفید، خط ink، سایه‌ی سخت)، `sel` انتخاب‌شده در آزمون (پر `pri`، متن سفید، شماره روی ink)، `right` درست (`green-soft`، خط و شماره‌ی `green-dk` با ✓)، `wrong` غلط (`bad-soft`، خط `bad`، شماره با ✕، یک بار shake)، `static` برای نمایش در باتم‌شیت پاسخ (بدون سایه).

**رفتار:** در آزمون، زدن دوباره روی گزینه‌ی انتخاب‌شده جواب را پاک می‌کند. در آزمون هیچ‌وقت درست یا غلط نشان داده نمی‌شود؛ `right` و `wrong` فقط در مأموریت و کارنامه.

- باید: شماره‌ها ۱ تا ۴ با رقم فارسی، همان شماره‌گذاری کتاب‌های تست.
- نباید: رنگ تنها نشانه باشد؛ ✓ و ✕ و برچسب «جواب درست» / «جواب تو» همراهش است.
