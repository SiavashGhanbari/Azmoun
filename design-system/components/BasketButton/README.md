# BasketButton

دکمه‌ی سبد «از معلم می‌پرسم» با شمارنده؛ بالای خانه و در هدر تمرین.

**ساختار:** `icon-btn basket-btn` با آیکون سبد و `.cnt` (دایره‌ی `terra` با خط `ink`) وقتی سبد خالی نیست.

**موشن:** وقتی دانش‌آموز سؤالی را در سبد می‌اندازد، کارت سؤال کوچک می‌شود و با یک قوس (۰٫۷۶ ثانیه) می‌افتد توی همین دکمه؛ بعد دکمه `bump` می‌کند و عدد با `pop` عوض می‌شود.

- باید: `aria-label` تعداد سؤال‌ها را بگوید.
- نباید: در قصه‌ی نتیجه دیده شود.
