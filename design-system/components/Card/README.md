# Card

دو نوع کارت داریم و تفاوتشان معنا دارد: کارت نمایشی (`card`) سفید با سایه‌ی نرم و بدون خط؛ کارت کلیک‌خور (`card tap`) با خط ink و سایه‌ی سخت.

**کی:** هر چیزی که کلیک‌خور نیست سایه‌ی نرم `soft` می‌گیرد؛ هر چیزی که کلیک‌خور است خط `stroke` و سایه‌ی `hard`. این قاعده در کل اپ ثابت است و کاربر از روی آن تشخیص می‌دهد کجا را بزند. `card flat` روی باتم‌شیت یا داخل کارت دیگر استفاده می‌شود.

**رفتار:** کارت کلیک‌خور هنگام فشردن سر جایش می‌ماند و فقط سایه‌اش جمع می‌شود (فرو نمی‌رود). گوشه `radius-lg`، padding ‏`space-6`.

- نباید: کارت نمایشی با خط مشکی، یا کارت کلیک‌خور بدون سایه‌ی سخت.
- نباید: نوار رنگی کنار کارت.
