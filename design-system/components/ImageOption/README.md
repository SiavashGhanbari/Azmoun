# ImageOption

گزینه‌ی تصویری برای سؤال‌هایی که جواب‌هایشان شکل است.

**ساختار:** `.opts-img` (شبکه‌ی دوستونه) ← `button.opt.img` با شماره‌ی کوچک در گوشه‌ی راست‌بالا و `img.opt-img`. انتخاب‌شده: زمینه‌ی `pri-soft` و قاب `pri` داخل خط `ink`.

- باید: هر تصویر `alt` فارسی داشته باشد که شکل را توصیف کند؛ تصویرها هم‌اندازه و مربع.
- نباید: ترکیب گزینه‌ی متنی و تصویری در یک سؤال.
