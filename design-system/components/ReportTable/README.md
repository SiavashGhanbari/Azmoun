# ReportTable

جدول کارنامه: برای هر دفترچه تعداد درست، غلط، نزده و درصد (با نمره‌ی منفی)، و یک ردیف جمع.

**ساختار:** `card rep` ← `.rep-h` (سرستون‌ها) و `.rep-r` برای هر دفترچه با نام و ضریب؛ ردیف آخر `.rep-r.sum` با خط `ink` بالایش. درست `green-dk`، غلط `bad`.

- باید: زیر جدول یک `note` که قانون نمره‌ی منفی را بگوید. درصدها یک رقم اعشار با «٫».
- نباید: ستون بیشتر از ۵ تا؛ در گوشی جا نمی‌شود.
