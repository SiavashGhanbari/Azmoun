# PracticeLevels

فهرست تمرین‌های یک آزمون در سه سطح ساده، متوسط و سخت.

**ساختار:** برای هر سطح یک `list-item` با عنوان، «N از M سؤال» و `.progress`. اولین سطحِ تمام‌نشده بج `pri` «از اینجا» دارد؛ سطح تمام‌شده بج `ok` «تموم شد». اگر در سطحی هیچ سؤال غلط یا بی‌جوابی نباشد، ردیف فقط‌نمایشی (`static`) با ✓ می‌آید.

**قاعده:** سطح هر سؤال از روی جواب همه‌ی شرکت‌کننده‌ها معلوم می‌شود (۵۰٪ به بالا درست = ساده). تمرین همیشه از ساده‌ها شروع می‌شود.

- باید: هر سه سطح قابل باز کردن باشند؛ ترتیب فقط پیشنهاد است.
