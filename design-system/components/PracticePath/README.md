# PracticePath

مسیر تمرین یک آزمون: ایستگاه‌ها روی یک خط‌چین، از بالا به پایین.

**ساختار:** `.path` ← `.path-h` (عنوان بخش: «دفترچه‌ی ۱ · راه‌حل و سؤال مشابه»، «دفترچه‌ی ۲ · مسیر سرعت») ← دکمه‌های `.stn` با `.stn-node` (دایره‌ی روی خط) و `.stn-card`. آخر مسیر `.path-end` با پرچم.

**حالت‌ها:** عادی (شماره یا آیکون صاعقه برای ایستگاه سرعت)، `cur` (گره‌ی `pri` که آرام می‌تپد، با بج «از اینجا»)، `done` (گره‌ی سبز با تیک و بج «تموم شد»).

**قاعده:** ایستگاه‌های دفترچه‌ی ۱ سه سطح ساده، متوسط و سخت‌اند و نوار پیشرفت دارند. ایستگاه‌های دفترچه‌ی ۲ هر کدام یک دسته‌ی سؤال‌اند و به‌جای پیشرفت، رکورد یا تعداد تلاش را نشان می‌دهند.

- باید: همه‌ی ایستگاه‌ها قابل باز کردن باشند؛ ترتیب فقط پیشنهاد است.
- نباید: سطحی که سؤال غلط یا بی‌جواب ندارد در مسیر بیاید.
