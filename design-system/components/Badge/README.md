# Badge

برچسب کپسولی کوچک برای وضعیت یا ویژگی یک آیتم.

**تون‌ها:** پیش‌فرض (surface با خط line)، `ok` سبز (قابل شرکت، تحویل داده شد، رایگان)، `warn` نارنجی‌خاکی (نیمه‌کاره، بی‌جواب)، `pri` بنفش (نتیجه آمده، آموزش، پیشنهاد).

- باید: یک یا دو کلمه؛ تون معنا دارد، نه تزئین.
- نباید: بج کلیک‌خور؛ برای کار، دکمه بگذارید.
