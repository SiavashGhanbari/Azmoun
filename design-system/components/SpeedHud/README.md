# SpeedHud

اجزای بازی «مسیر سرعت» (تمرین دفترچه‌ی ۲): جون‌ها، نقطه‌های پیشرفت، نوار زمان، نشان پشت‌سرهم و گزینه‌های دوستونه.

**ساختار:**
- `.hearts`: سه قلب؛ قلبِ ازدست‌رفته `off` (توخالی). موقع از دست رفتن، `heart-break`.
- `.gdots`: برای هر سؤال یک تکه؛ `ok` سبز، `bad` قرمز، `cur` مشکی و بلندتر.
- `.gtime > #gbar` با عدد ثانیه کنارش؛ زیر ۵ ثانیه `low` می‌شود (قرمز و لرزان).
- `.streak`: از دو جواب درست پشت هم به بعد.
- `.gopts`: گزینه‌ها دوستونه؛ اگر متن بلند بود `.gopts.one`.

**قاعده‌ی بازی:** ۸ سؤالِ تازه از همان دسته، هر سؤال ۱۵ ثانیه، ۳ جون. جواب غلط یا تمام شدن وقت یک جون کم می‌کند؛ با صفر شدن جون‌ها بازی با سؤال‌های تازه از اول شروع می‌شود. قبل از شروع یک شمارش ۳، ۲، ۱ هست. سبد ندارد.

- باید: بعد از هر جواب، درست و غلط با ✓/✕ هم نشان داده شود، نه فقط رنگ.
- نباید: ستاره یا امتیاز؛ تنها پاداش‌ها «آفرین»، نشان پشت‌سرهم و رکورد زمان‌اند.
