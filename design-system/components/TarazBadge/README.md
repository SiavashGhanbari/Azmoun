# TarazBadge

نمایش بزرگ تراز در قصه‌ی نتیجه، با چیپ رتبه و میانگین.

**ساختار:** `.taraz > b` روی `pri` با خط `ink`؛ عدد از ۵٬۰۰۰ (میانگین) تا تراز دانش‌آموز شمرده می‌شود. زیرش `.wf-chips` با `.chip-up` (سبز، خبر خوب) و `.chip-up.plain` (خنثی).

- باید: عدد با جداکننده‌ی هزارگان فارسی (٬) و `tabular-nums`.
- نباید: استفاده برای عددی غیر از تراز.
