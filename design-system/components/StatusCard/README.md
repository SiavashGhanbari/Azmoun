# StatusCard

کارت «الان چه کاری داری» در خانه و صفحه‌ی آزمون و تمرین. همیشه فقط یکی از این‌هاست: آزمونِ آماده، آزمون نیمه‌کاره، منتظر نتیجه، نتیجه‌ی تازه، تمرینِ همان آزمون، یا «همه‌چی انجام شد».

**ساختار:** `card status` با بج وضعیت، تیتر `heading`، یک خط توضیح، تصویرسازی کوچک در چپ، در صورت نیاز `.progress` و یک دکمه‌ی اصلی.

- باید: فقط یک دکمه‌ی اصلی؛ آزمون و تمرین هیچ‌وقت هم‌زمان نشان داده نمی‌شوند.
- نباید: خودِ کارت کلیک‌خور باشد (سایه‌ی نرم دارد)؛ کار با دکمه‌ی داخلش انجام می‌شود.
