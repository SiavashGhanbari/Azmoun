# IconButton

دکمه‌ی گرد ۴۲px سفید با خط ink و سایه‌ی سخت کوچک، برای برگشت، بستن و کارهای تک‌آیکونی.

**کی:** گوشه‌ی راست هدر برای برگشت (فلش به راست)، بستن آزمون (✕)، تغییر عکس پروفایل. آواتار در هدر خانه همین رفتار را با کلاس `av-btn` دارد.

**ساختار:** `<button class="icon-btn" aria-label="…">` + یک آیکون ۲۰px با `currentColor`. همیشه `aria-label` فارسی بدهید.

- نباید: آیکون بدون برچسب دسترسی؛ نباید: فلش برگشت به چپ (در راست‌به‌چپ برگشت به راست است).
