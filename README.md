# آزمون

پروتوتایپ اپ آزمون و یادگیری برای دانش‌آموزان پایه‌ی پنجم و ششم ابتدایی. دانش‌آموز آزمون دو دفترچه‌ای می‌دهد، کارنامه و رتبه‌ی مدرسه‌اش را می‌بیند، از روی اشتباه‌هایش مأموریت تمرینی می‌گیرد و سؤال‌هایی را که نفهمیده در سبد «از معلم می‌پرسم» نگه می‌دارد.

کل اپ HTML و جاوااسکریپت ساده است، بدون فریم‌ورک و بدون سرور. خروجی یک فایل HTML تک است (`index.html`) که فونت و تصویرها داخلش است و بدون اینترنت باز می‌شود.

## اجرا

`index.html` را در Chrome یا Safari باز کنید. بهترین تجربه روی گوشی است.

اطلاعات تست (کامل‌ترش در `TESTING.txt`):

- کد پیامک: `12345`
- کد دعوت: `AZ1405`
- کد ملی معتبر: `0012345679`
- شماره‌ی ثبت‌نشده (برای دیدن خطا): `09120000000`

هر شماره‌ی موبایل داده‌ی جدای خودش را دارد و پیشرفت فقط در مرورگر همان تست‌کننده (localStorage) ذخیره می‌شود. دکمه‌های «حالت تست» در خانه و پروفایل نتیجه را اعلام می‌کنند، آزمون را از نو می‌دهند یا همه‌چیز را پاک می‌کنند.

## ساختار

```
index.html            اپ (ساخته‌شده؛ دستی ویرایش نکنید)
TESTING.txt           راهنمای تست‌کننده‌ها
src/
  app.js              داده‌ها، وضعیت، مسیریابی و همه‌ی صفحه‌ها
  assets.js           تصویر سؤال و ۸ آواتار به‌صورت data URI
  style.css           استایل
  fonts/              یکان بخ (فونت متغیر)
  images/             فایل اصلی تصویرهای سؤال
design-system/        دیزاین سیستم اپ
build.py              ساخت index.html از روی src/
```

## ساختن دوباره

بعد از هر تغییر در `src/`:

```bash
python3 build.py
```

این دستور `index.html` را از نو می‌سازد. فونت و `assets.js` داخل فایل خروجی جاسازی می‌شوند.

## دیزاین سیستم

`design-system/`:

- `README.md`: راهنمای برند (لحن، رنگ، تایپ، فاصله، خط و سایه، حرکت، آیکون، دسترس‌پذیری)
- `tokens.json` و `tokens.css`: توکن‌ها
- `components/`: ۲۶ کامپوننت، هر کدام با راهنما و پیش‌نمایش
- `assets/`: ۲۵ آیکون، ۸ تصویرسازی، ۸ آواتار
- `fonts/`: یکان بخ

نسخه‌ی زنده‌اش در claude.ai هم به‌عنوان دیزاین سیستم «آزمون» ذخیره شده و در Claude Design قابل انتخاب است.
