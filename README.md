# آزمون

پروتوتایپ اپ آزمون و یادگیری برای دانش‌آموزان پایه‌ی پنجم و ششم ابتدایی. دانش‌آموز آزمون دو دفترچه‌ای می‌دهد، کارنامه و رتبه‌ی مدرسه‌اش را می‌بیند، از روی اشتباه‌هایش مأموریت تمرینی می‌گیرد و سؤال‌هایی را که نفهمیده در سبد «از معلم می‌پرسم» نگه می‌دارد.

کل اپ HTML و جاوااسکریپت ساده است، بدون فریم‌ورک و بدون سرور. هر نسخه یک فایل HTML تک است که فونت و تصویرها داخلش است و بدون اینترنت باز می‌شود.

## دو نسخه‌ی ظاهری

| نسخه | فایل | سبک |
| --- | --- | --- |
| ۱ | `app/v1/index.html` | کاغذی؛ خط مشکی و سایه‌ی سخت برای هر چیز کلیک‌خور، بنفش `#947EDC`، تصویرسازی خطی |
| ۲ | `app/v2/index.html` | کرم گرم؛ دکمه‌های کپسولی مشکی، هاله‌ی نارنجی‌صورتی، «موج سؤال‌ها» به‌جای پراگرس، ردیف‌های خط‌نازک به‌جای کارت |

منطق و داده‌ی هر دو نسخه یکی است؛ فقط صفحه‌ها و استایل فرق دارند.

## اجرا

فایل `index.html` ریشه را باز کنید و یکی از نسخه‌ها را بزنید، یا مستقیم `app/v1/index.html` یا `app/v2/index.html` را در Chrome یا Safari باز کنید.

اطلاعات تست (کامل‌ترش در `app/TESTING.txt`):

- کد پیامک: `12345`
- کد دعوت: `AZ1405`
- کد ملی معتبر: `0012345679`
- شماره‌ی ثبت‌نشده (برای دیدن خطا): `09120000000`

هر شماره‌ی موبایل داده‌ی جدای خودش را دارد و پیشرفت فقط در مرورگر همان تست‌کننده (localStorage) ذخیره می‌شود. دکمه‌های «حالت تست» در خانه و پروفایل نتیجه را اعلام می‌کنند، آزمون را از نو می‌دهند یا همه‌چیز را پاک می‌کنند.

## ساختار

```
index.html            صفحه‌ی انتخاب نسخه
app/
  v1/index.html       نسخه‌ی ۱ (ساخته‌شده؛ دستی ویرایش نکنید)
  v2/index.html       نسخه‌ی ۲ (ساخته‌شده؛ دستی ویرایش نکنید)
  TESTING.txt         راهنمای تست‌کننده‌ها
src/
  app.js              داده‌ها، وضعیت، مسیریابی و صفحه‌های نسخه‌ی ۱
  assets.js           تصویر سؤال و ۸ آواتار به‌صورت data URI
  v1/style.css        استایل نسخه‌ی ۱
  v2/v2views.js       صفحه‌های نسخه‌ی ۲ (روی app.js بازنویسی می‌شوند)
  v2/style2.css       استایل نسخه‌ی ۲
  fonts/              یکان بخ (فونت متغیر)
  images/             فایل اصلی تصویرهای سؤال
design-system/v1/     دیزاین سیستم نسخه‌ی ۱
tests/flow-test.js    تست کامل مسیرهای نسخه‌ی ۲ با Playwright
build.py              ساخت هر دو نسخه
```

## ساختن دوباره

بعد از هر تغییر در `src/`:

```bash
python3 build.py
```

این دستور `app/v1/index.html` و `app/v2/index.html` را از نو می‌سازد. فونت و `assets.js` داخل فایل خروجی جاسازی می‌شوند.

نسخه‌ی ۲ همان `app.js` را بارگذاری می‌کند و بعد `v2views.js` را اضافه می‌کند. تابع‌ها و صفحه‌های `V.*` بازنویسی می‌شوند و `render()` آخر از همه صدا زده می‌شود. پس منطق مشترک (ورود، ثبت‌نام، آزمون، کارنامه، مأموریت‌ها، سبد) فقط در `app.js` است.

## تست

```bash
npm i playwright
node tests/flow-test.js
```

تست کل مسیر نسخه‌ی ۲ را می‌رود (ثبت‌نام، معرفی، آزمون، شبکه‌ی سؤال‌ها، کارنامه، رتبه‌بندی، مأموریت‌ها، پروفایل، سبد)، از هر صفحه عکس می‌گیرد و در `tests/screens/` می‌گذارد. در پایان خطاهای جاوااسکریپت و صفحه‌هایی را که اسکرول افقی دارند چاپ می‌کند.

## دیزاین سیستم

`design-system/v1/` دیزاین سیستم نسخه‌ی ۱ است:

- `README.md`: راهنمای برند (لحن، رنگ، تایپ، فاصله، خط و سایه، حرکت، آیکون، دسترس‌پذیری)
- `tokens.json` و `tokens.css`: توکن‌ها
- `components/`: ۲۶ کامپوننت، هر کدام با راهنما و پیش‌نمایش
- `assets/`: ۲۵ آیکون، ۸ تصویرسازی، ۸ آواتار
- `fonts/`: یکان بخ

نسخه‌ی زنده‌اش در claude.ai هم به‌عنوان دیزاین سیستم «آزمون» ذخیره شده و در Claude Design قابل انتخاب است.
